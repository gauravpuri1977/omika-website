OMIKA COUTURE — SAMPLE 3 / ATELIER SIGNATURE EXPERIENCE

This is the enhanced, separate static homepage prototype for:
https://omikacoutures.com/sample3/

DESIGN DIRECTION
- Graceful forest-black, deep green, sage and warm-ivory palette.
- Original Omika wordmark, four fashion films, and catalogue imagery.
- Editorial video runway followed by a clear brand statement, curated edit, brand story, mood-based category discovery, Adah and Rasika signature collections, style inspiration and a wholesale pathway.
- Full-length catalogue images preserve their original portrait composition; cards use source-matched framing instead of zoom-cropping the models or garments.
- Thoughtful hover states, subtle scroll reveals, collection search and filters, quick-look modal, locally saved looks, responsive navigation and playback controls.
- Keyboard focus, skip navigation, Escape-to-close mobile menu, reduced-motion support, lazy-loaded media, poster fallbacks and responsive layouts.
- Broken image cards are removed instead of leaving empty image containers.
- Preview page is marked noindex so the /sample3/ experiment does not compete with the eventual production homepage in search results.

PACKAGE CONTENTS
sample3/index.html
sample3/assets/ (Omika logo, four compressed silent fashion films, posters, and catalogue images)
README.txt
DEPLOYMENT_NOTES.txt

IMPORTANT LIMITATIONS
This is a polished front-end concept, not a live ecommerce backend. It does not include real product SKUs/prices, inventory, checkout, payments, shipping integration, customer accounts, newsletter capture, or approved legal policy pages. The shopping bag is a visual empty-state preview; it cannot accept orders. Saved looks stay in the visitor's browser and are not account-synchronised. Payment marks shown in the footer are visual placeholders until the actual gateway and supported methods are confirmed. Do not advertise this prototype as accepting orders until commerce integrations are completed.

PUBLISH TO /sample3/
1. Extract the deployment ZIP.
2. Upload the included sample3/ folder and its assets/ directory into the existing GitHub Pages publishing root.
3. Do not replace the root index.html, root CNAME, or sample2/.
4. Commit to the branch/folder configured for GitHub Pages.
5. After GitHub Pages finishes deploying, open https://omikacoutures.com/sample3/.

The root homepage, DNS and /sample2/ are not changed by this package.
