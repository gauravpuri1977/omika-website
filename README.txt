Preview locally
---------------
1. Extract the ZIP.
2. Keep index.html and the entire assets folder together.
3. Double-click index.html to preview in a browser.

Publishing to GitHub Pages
--------------------------
1. Open the Omika website repository.
2. Upload index.html to the repository root.
3. Upload the complete assets folder to the same repository root.
4. Keep the existing CNAME file and domain configuration unchanged.
5. Commit only when ready to replace the current live Coming Soon page.

Important
---------
- All four video files have had their audio tracks removed; the HTML also sets
  muted, loop, autoplay and playsinline.
- The site is a front-end design prototype. Product/category destinations,
  search, shopping bag, actual product listings, and wholesale contact workflow
  are not connected yet.
- Category imagery is taken from the supplied Omika videos as temporary
  editorial/category imagery. Replace with approved category-specific images
  as the catalogue is finalised.
- Do not upload only index.html: the assets folder is required for the videos
  and category images to display.
